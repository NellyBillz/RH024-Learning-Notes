# 03. Documentation

## What I learned

Linux ships with local help. Manual pages explain syntax and options; `--help` often gives a shorter summary. Documentation matters because flags and behaviour vary by command and release.

## Key idea

Use `man`, `apropos`, and `info` when available. Section numbers distinguish similarly named manual pages. `q` exits the manual viewer.

## Commands to explore

```bash
man ls
ls --help
apropos permissions
```

## Practice

Find the option for showing hidden files in `ls`, and record which help source you used.
