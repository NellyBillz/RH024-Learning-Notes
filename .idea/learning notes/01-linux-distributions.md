# 01. Linux distributions

## What I learned

Linux is a kernel; a distribution combines it with user tools, a package manager, configuration, and support. RHEL is an enterprise distribution with a managed lifecycle. Fedora and CentOS Stream have different roles in the Red Hat ecosystem.

## Key idea

A distribution determines available packages, default configuration, update processes, and support expectations. Check the actual host before using distribution-specific instructions.

## Commands to explore

```bash
cat /etc/os-release
uname -r
```

## Practice

Identify the distribution and kernel version. Explain why they are not the same thing.
