# 07. Editing files with Vim

## What I learned

Vim is a modal text editor. Normal mode accepts navigation and commands, insert mode enters text, and command-line mode saves or quits.

## Key idea

Press `i` to insert, `Esc` to return to normal mode, `:w` to save, `:q` to quit, and `:wq` to save and quit. `:q!` discards unsaved edits.

## Commands to explore

```bash
vim "$HOME/rh024-practice/vim-notes.txt"
```

## Practice

Write three lines, save, reopen the file, edit a line, then quit. Note what changed on disk.
